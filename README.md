## 🛡️ Pourquoi la Souveraineté Numérique ?

Je ne construis pas Gauzian pour "concurrencer les géants".
Je le construis parce que **les alternatives actuelles sont inacceptables** :

- ❌ Vos fichiers scannés par des IA pour de la pub ciblée
- ❌ Vos données hébergées hors UE sans contrôle réel
- ❌ Des CGU qui changent du jour au lendemain
- ❌ Aucune garantie sur ce qui arrive à vos données

**Gauzian, c'est :**
- ✅ **Zero-Knowledge** : le serveur ne voit jamais vos données en clair (RSA-4096 + AES-256-GCM)
- ✅ **Hébergement français** : conformité RGPD stricte, gouvernance européenne
- ✅ **Auto-hébergeable** : Docker Compose + manifests K8s inclus
- ✅ **Open roadmap** : vous savez ce qui se construit et pourquoi
- ✅ **Pas de tracking** : zéro analytics, zéro profilage, zéro revente de données

## 🚀 Phase Actuelle : Transition Microservices

Je refactorise actuellement l'architecture monolithique de Gauzian vers des **microservices indépendants** :

```
Monolithe Rust  →  Auth Service + Drive Service + Agenda Service + ...
```

**Pourquoi cette transition ?**
- Scalabilité indépendante (chaque service selon ses besoins)
- Déploiements isolés (zéro impact entre services)
- Développement parallèle (équipes autonomes par service)
- Sécurité renforcée (isolation des données)

Si vous avez de l'expérience en architectures distribuées, **parlons-en** ! 🚀
